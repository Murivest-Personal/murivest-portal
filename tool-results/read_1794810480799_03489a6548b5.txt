     1→// =====================================================================
     2→// Murivest Private Capital Portal — Prisma Schema
     3→// ---------------------------------------------------------------------
     4→// Runtime schema for the Next.js application. The sandbox/dev runtime
     5→// uses SQLite. For production, switch the provider to "postgresql"
     6→// and point DATABASE_URL at your managed instance, then run
     7→// `prisma db push` (or apply sql/001_schema.sql + 002_rls.sql first).
     8→//
     9→// NOTE (SQLite runtime): enums are not supported by the SQLite
    10→// connector, so constrained fields are declared as String and enforced
    11→// at the application layer (zod schemas in src/lib/validation.ts).
    12→// The production PostgreSQL DDL (sql/001_schema.sql) declares the
    13→// same constraints as native ENUM / CHECK constraints.
    14→//
    15→// Content objects (opportunities, briefs, data-room documents, market
    16→// intelligence reports, landing content) are authored in Sanity and
    17→// fetched with GROQ — they are NOT duplicated here. Local tables track
    18→// every *interaction* with that content (saves, views, grants, access
    19→// logs, orders) keyed by the Sanity document id.
    20→// =====================================================================
    21→
    22→generator client {
    23→  provider = "prisma-client-js"
    24→}
    25→
    26→datasource db {
    27→  provider = "sqlite"
    28→  url      = env("DATABASE_URL")
    29→}
